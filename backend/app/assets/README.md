# Logo CEBEVIRHA

Déposez ici le fichier `logo_cebevirha.png` (logo officiel, fond
transparent de préférence, ~300x300 px suffit) pour qu'il apparaisse
automatiquement en en-tête de la facture PDF (Module 1).

Aucune modification de code nécessaire — `app/services/pdf_facture.py`
détecte ce fichier tout seul. Sans lui, l'en-tête reste textuelle.
